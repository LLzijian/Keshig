# 验证范围

0.3.1 提供以下自动化验收，运行入口为 `python tools/validate_bundle.py`。所有个人资料均为临时目录中的虚构数据。

- 默认全量安装、漂移检测、备份更新、任意目录联接拒绝及已知共享技能入口复用。
- 源码或技能内的个人目录拒绝；配置越界与 Windows 目录联接越界时，在写入前停止。
- 从安装副本初始化个人系统，验证训练计划和营养示例，读取虚构复盘，升级后逐文件核对，移动目录后继续检查。
- 暂存区内容与工作区内容分别检查；已删除个人文件的历史仍被发现；发布包排除忽略目录。
- VitalDock `agent/1` 成功、空记录、格式异常、认证错误、限流和错误输出保密；安装失败后继续；授权缺失后恢复；读取上游时不生成缓存文件。

2026-11-03，在 Windows / Python 3.12 完成整包校验；本地提交与推送 hooks 的拦截和修正后继续也已通过。另在独立临时个人目录实际下载固定提交、安装 VitalDock 0.4.0，并完成不联网的版本自检；没有读取账号或凭据。CI 配置覆盖 Windows、Linux 与 Python 3.10、3.12，远端结果须以实际执行为准。训练系统要求 Python 3.10+，可选设备环境要求 Python 3.11+。

自动化文件流程不等于陌生用户的对话验收。尚需在新用户实际使用的 Agent 中完成建档、现场负荷校准、第一份正式计划和一次真实复盘；真实华为授权、不同地区账号、macOS 凭据服务与 Linux 密钥服务需分别实测。

固定依赖来源见[版本记录](../skills/training-system/references/vitaldock.json)。设备协议测试使用构造的 CLI，不接触账号或凭据；完整个人接入只有实际授权和读取成功后才可报告完成。
