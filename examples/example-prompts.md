# Keshig 示例任务

以下示例不包含真实用户数据。

## 首次建档

```text
开始建立我的健身系统。我的目标是增肌和基础力量，每周可以训练四次，每次 75 分钟，有商业健身房器械。
```

## 个性化计划

```text
使用 $fitness-plan。我的目标是增肌和基础力量，每周可以训练四次，每次 75 分钟，有商业健身房器械。请先完成最少必要问诊，再生成状态快照、训练计划 JSON 和 Markdown 计划书。
```

## 中断接回

```text
使用 $training-return。我停训了 14 天，之前每周三练，现在只有 30 分钟。请先判断恢复权限，再给正常、降级、最低三档任务和七天接回卡。
```

## 单项周期

```text
使用 $strength-cycle-planner。请根据我最近三次卧推记录制定 8 周周期，写清顶组、回退组、未完成分支、减量和测试，并输出 Markdown 周期计划书。
```

## 训练复盘

```text
使用 $strength-training-review。我没有多周周期，下面是最近三次同标准深蹲记录。请判断我的渐进方式是否合适，给出下一次处方并保存复盘记录。
```

## 周训练复盘

```text
使用 $strength-training-review。请总结我这周训练：先核对计划与实际，再问我的个人体感；如果发现重复问题或含糊记录，先追问原因，最后给出下周唯一重点和可沉淀的关键决策。
```

## 饮食建档

```text
使用 $nutrition-system。帮我建立饮食目标。先问我采用哪种方法、每周训练时长和当前体重，不要拿通用表格冒充我的口径。
```

## 学习一个视频

```text
使用 $video-learning。请学习这个视频并整理成来源限定的笔记，区分作者原话、画面观察和你的推断，不要把建议写成已经执行的处方。
```
